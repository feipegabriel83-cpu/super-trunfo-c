# super-trunfo-c
Projeto em C simulando um cadastro do Super Trunfo

Um Projeto simples envolvendo a Linguagem de Programação C para um cadastro de cartas do jogo Super Trunfo

#Funcionalidades:
-- Cadastro de duas cartas;
-- Entrada de Dados via terminal;
-- Exibição das informações formatadas.

#Tecnologias
-- Linguagem C

#Objetivos
-- Pratica de conceitos basicos de programação em C.
